# 键盘独立配置

此修改增加键盘独立模型设置，供 App Group 无法共享配置时使用。不修复签名权限，不保证直播共享。核心模型请求和聊天生成逻辑保持原样。

## 安装后的使用

1. 在系统设置中给 Jev 键盘开启“允许完全访问”。
2. 主 App 模型页配置生成层和可选判断层，滚到底部，点“复制配置供键盘独立导入”，确认复制。此操作包含 Key，只复制到本机剪贴板，60 秒后过期。不要粘贴到聊天发送。
3. 在任意支持第三方键盘的输入框切到 Jev，点顶部齿轮。点“从主 App 导入剪贴板配置”，然后滚到底部点“保存并使用独立配置”。成功导入后清空该配置剪贴板，避免误发密钥。
4. 返回键盘，分析剪贴板或输入框文字。准备分析的聊天文本需要重新复制。
5. 日后在主 App 修改模型不会覆盖键盘独立配置。需要重复导入并保存，或在键盘设置清除独立配置，恢复读取主 App。

也可选择服务预设，分别复制地址、模型、Key，再点各字段的“粘贴”。键盘扩展不能弹出另一套系统键盘来编辑自己的文本框，因此采用显式粘贴按钮。未保存修改在关闭配置页或扩展进程退出后丢弃。

Key 默认隐藏，不提供复制/显示密钥按钮。保存的整个独立配置使用键盘进程默认钥匙串，不申请额外共享钥匙串组，解锁时可读且不同步其他设备。保存失败会显示系统错误码，请保留错误码供排查。卸载或换签名后钥匙串数据的保留/可访问性取决于系统及签名身份；可用清除按钮主动删除。此版本仅允许独立配置使用 HTTPS。

独立配置涵盖生成接口、Key、模型、额外 JSON、判断接口和话术。键盘内的话术选择会写回独立配置。语言、直播、主 App 键盘状态仍沿用原共享路径，不属于此修复。设置页暂为中文。

## 构建

使用仓库原有 `.github/workflows/ios-build.yml`。必须先运行 `xcodegen generate`，它会把新增的 `Keyboard/Sources/KeyboardLocalSettings.swift` 加入工程。不要只打开旧的已提交工程直接构建。构建号提高到 4。

本地执行环境为 Linux，没有 Swift/Xcode。尚未完成 iOS 编译、模拟器或真机验证；必须以 GitHub Actions 的构建结果为准。不要把源码 ZIP 当作已编译 IPA。

仓库要求的 codex-claude-review 在当前环境不可用，未执行独立审查。
